# Custom Agent Rules for Tiny Thrive Theme

## Shopify Sync Rule
Before making any file modifications or starting a task/plan in this repository, you MUST:
1. Run `git pull` (or fetch from the remote) to download the latest edits committed by the Shopify Editor (`shopify[bot]`).
2. Always resolve any conflicts carefully, ensuring that settings or section edits made via the Shopify Editor are preserved.
3. When applying new edits locally, push them back to the repository so they are synced back to Shopify.
